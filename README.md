# 家庭经济困难学生认定申请表 · 交互填写（网页版）

单文件网页应用，无需服务器、无需数据库。所有数据保存在**使用者本机浏览器**里，不会上传到任何服务器。

## 目录

```
index.html      ← 全部内容（页面 + 样式 + 脚本 + DOCX 模板，全部内嵌）
README.md
```

`index.html` 是完全自包含的：省市区数据、Word 模板（base64）、样式脚本都在文件内部，**没有任何外部依赖**，断网也能填写（只是不能导出的除外）。

## 部署到 GitHub Pages（3 步）

1. **创建仓库并推送**
   - 用 GitHub Desktop 打开本目录（File → Add Local Repository → 选择本文件夹）
   - 提交（Commit）→ 点 **Publish repository**
   - 仓库名建议：`jjdk-form`；**Public / Private 都可以**（Pages 对免费账号的私有仓库有限制，建议 Public）

2. **开启 Pages**
   - 打开仓库网页 → **Settings → Pages**
   - Source 选择 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)`，点 **Save**

3. **等待生效**
   - 约 1 分钟后，地址为：`https://<你的用户名>.github.io/<仓库名>/`
   - 用手机微信打开该地址，即可填写；长按页面可收藏、可转发

## 本地预览

```
python -m http.server 8080
```

然后浏览器打开 `http://127.0.0.1:8080/`。直接双击 `index.html` 也能用，但 `file://` 协议下部分浏览器会限制本地存储，**草稿可能无法保存**，建议用上面的方式。

## 注意事项

1. **草稿按域名保存。** 换网址（比如从本地文件换成 github.io）不会带过去，所以正式地址定下来后不要再改。
2. **微信内置浏览器不能导出 Word。** 点击导出会提示"用浏览器打开"，按提示换到系统浏览器（Safari / Chrome）再导出即可。
3. **导出的是 .docx**，用 Word / WPS 打开后打印，再手写签名与日期。
4. 页面不需要登录，任何拿到链接的人都能填写，但**填写内容只存在他自己的手机里**，不会汇总到任何地方——收集时仍需学生自己导出后提交。
